# Enquête prix — eau au collagène vegan (A) vs bovin (B)

- `QUESTIONNAIRE.md` : questionnaire complet et plan d'analyse.
- `index.html` : version interactive (ouvrir dans un navigateur). Attribution aléatoire A/B, filtres de fin, Van Westendorp avec contrôle de cohérence, Gabor-Granger descendant (3,50 → 1,50 €, arrêt au premier « Certainement/Probablement »), contrôle de manipulation (`controle_ok`), Likert facultatif, profil. Les réponses sont stockées localement et exportables en CSV (séparateur `;`).
